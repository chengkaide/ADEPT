ADEPT 可视化工作台 · 使用说明
=============================

## 1. 输入数据

支持三种 Excel 格式（列名必须完全一致，注意大小写）：

| 格式 | 需要的列 |
|---|---|
| 1 · 直接年龄 | `Analysis`, `Time`, `Age68`, `Age75`, `Age76` |
| 2 · 原始计数 | `Analysis`, `Time`, `Pb206`, `Pb207`, `U238` |
| 3 · 同位素比值 | `Analysis`, `Time`, `Pb206_U238`, `Pb207_U235`, `Pb207_Pb206` |

格式 2 / 3 需要额外安装 `IsoplotR`（`install.packages("IsoplotR")`）来把比值换算成年龄。

列名里的空格和斜杠会被自动替换成下划线。除上表之外的**数值列**（如微量元素）
会被自动识别，并在结果里输出各自年龄坪内的均值。

一个 Excel 文件可以有多个工作表，每个工作表按 `每个锆石的行数`（默认 411）
切分成若干锆石分别处理。

## 2. 参数含义

- **剥蚀时间窗口（起始 / 结束）**：只保留这段时间的信号，避开开头的信号爬升
  和结尾的穿透污染。默认 29–58 s。
- **方差阈值**：年龄坪内部的归一化方差上限。调小 → 更严格，坪更少更短；
  调大 → 更宽松。默认 0.1192（原文标定值）。
- **最小坪宽 (s)**：短于该时长的坪会被剔除（第一段豁免）。
- **年龄上/下限 (Ma)**：落在区间外的坪直接剔除。
- **筛选方向**：
  - `Forward` —— 期望年龄随深度**递增**（核部更老，例如正常生长环带）
  - `Reverse` —— 期望年龄随深度**递减**（例如核部更年轻、有继承核被剥穿）
- **MCMC**：调用 `mcp` 包做贝叶斯变点后验估计，需要额外安装
  `mcp` 和 JAGS（<https://mcmc-jags.sourceforge.io/>），未安装时该列留空。

## 3. 输出

- **年龄坪汇总**：只含通过全部四步筛选的坪。
- **完整结果**：全部坪 + 全部统计量（含被筛掉的，可用 `Filter 1..4` 列判断
  卡在哪一步）。
- 两张表都能在界面上直接复制 / 导出 CSV / Excel。
- 侧栏可下载 Excel 结果与全部剖面图的合并 PDF。

## 4. 建议的工作流

1. 先用**默认参数** + 载入示例数据跑一遍，确认流程通。
2. 在「数据预览」页确认格式识别正确。
3. 在「深度剖面」页逐个锆石看图，判断年龄趋势是递增还是递减，据此选方向。
4. 若坪太少 → 调大方差阈值或调小最小坪宽；若坪太碎 → 反向调整。
5. 参数满意后保存，并在论文方法部分写明所用参数。

## 5. 注意

年龄坪是**算法在给定参数下的最优分段**，不等同于地质上真实的结晶事件。
对铀矿、热液蚀变锆石等体系，U-Pb 体系可能遭受多期扰动，此时年龄坪未必有
地质意义，务必结合 CL / BSE 图像与微量元素剖面综合判断。
